**Como** cliente

**Quiero** ver el detalle de un producto

**Para** decidir con información suficiente si lo agrego a mi pedido

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente está en el menú, cuando toca la tarjeta de un producto, entonces la pantalla muestra imagen, nombre, descripción y precio base del producto.
- [ ] **CA-2** — Dado el producto tiene una descripción de más de 200 caracteres, cuando se abre el detalle, entonces la descripción se muestra completa y desplazable, sin cortar el texto.
- [ ] **CA-3** — Dado el cliente está en el detalle y no desea agregar el producto, cuando toca 'Volver al menú', entonces la pantalla regresa a la categoría y a la posición donde estaba el menú.
- [ ] **CA-4** — Dado el detalle muestra su acción principal, cuando el cliente toca esa acción, entonces el área táctil mide al menos 88 px de alto y responde en menos de 1 segundo.

## 4. Contexto

El cliente ya está consultando el menú y toca la tarjeta de un producto.

La pantalla de detalle muestra la información que permite decidir la compra sin obligar a volver al menú.

## 5. Reglas de negocio

- El detalle solo se abre para productos disponibles.
- El precio base mostrado excluye variantes y complementos, que se eligen en el paso siguiente.
