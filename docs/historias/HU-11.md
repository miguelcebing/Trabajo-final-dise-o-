**Como** cliente

**Quiero** recibir un aviso cuando mi pedido esté listo

**Para** no quedarme esperando frente a la pantalla

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado todos los sectores completaron sus tareas, cuando el pedido pasa a Listo, entonces la pantalla muestra un aviso destacado con el número de pedido y la mesa.
- [ ] **CA-2** — Dado el aviso está en pantalla, cuando el cliente toca 'Entendido', entonces el aviso se cierra y la pantalla vuelve a la vista anterior.
- [ ] **CA-3** — Dado hay varios pedidos listos al mismo tiempo, cuando se genera un aviso nuevo, entonces la pantalla muestra los avisos pendientes en orden de llegada.

## 4. Contexto

Cuando el pedido alcanza el estado Listo, la pantalla lo anuncia de forma visible.

El aviso complementa la consulta manual del estado.

## 5. Reglas de negocio

- El aviso se muestra una sola vez por pedido hasta que el cliente lo cierre.
- El aviso incluye el número de pedido y la mesa.
