## 2. Historia

Como **cocinero** quiero ver las tareas de mi sector para preparar solo lo que me corresponde.

## 3. Contexto

Cada sector tiene su propia pantalla.

Un pedido con productos de varios sectores se divide, y a cada sector le llega únicamente su parte.

## 4. Criterios de aceptación

- [ ] **CA-1** — Dado un pedido pagado incluye productos del sector Parrilla, cuando el pedido se envía a cocina, entonces la pantalla del sector Parrilla muestra una tarea nueva con el número de pedido y la mesa.
- [ ] **CA-2** — Dado el pedido incluye productos de varios sectores, cuando se envía el pedido, entonces cada sector recibe solo sus ítems y ninguno recibe ítems ajenos.
- [ ] **CA-3** — Dado no hay pedidos pendientes, cuando el cocinero consulta su pantalla, entonces la pantalla muestra el mensaje 'Sin tareas pendientes'.
- [ ] **CA-4** — Dado el cocinero toca 'Ver' en una tarea, cuando el toque se registra, entonces el botón responde con un área mínima de 88 px y abre el detalle de la tarea.

## 5. Reglas de negocio

- Cada sector visualiza únicamente las tareas de los productos que tiene asignados.
- Las tareas se muestran en orden de llegada del pedido.
