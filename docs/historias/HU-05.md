## 2. Historia

Como **cliente** quiero modificar las cantidades o eliminar productos del carrito para dejar el pedido exactamente como lo quiero antes de pagar.

## 3. Contexto

Antes de pagar, el cliente revisa el carrito y ajusta lo que necesite.

Cada cambio recalcula los totales de inmediato y en pantalla.

## 4. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente está en el carrito con un producto en cantidad 1, cuando toca '+', entonces la cantidad cambia a 2 y el subtotal del ítem y el total se recalculan.
- [ ] **CA-2** — Dado el cliente tiene un producto en cantidad 1, cuando toca '−', entonces el sistema solicita confirmación antes de quitar el ítem del carrito.
- [ ] **CA-3** — Dado el cliente tiene tres productos distintos en el carrito, cuando toca 'Quitar' en el segundo, entonces el ítem desaparece de la lista y el total se recalcula sin él.
- [ ] **CA-4** — Dado el carrito queda sin productos, cuando el cliente elimina el último ítem, entonces la pantalla muestra el carrito vacío y deshabilita el botón de continuar.

## 5. Reglas de negocio

- La cantidad mínima de un ítem es 1; para quitarlo se usa la acción 'Quitar'.
- El total se recalcula después de cada cambio, sin acción adicional del cliente.
