**Como** cliente

**Quiero** indicar mi mesa

**Para** que el pedido se entregue en el lugar correcto

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente ya tiene productos en el carrito y toca 'Continuar', cuando la pantalla muestra la grilla de mesas, entonces el cliente ve las mesas numeradas y su estado.
- [ ] **CA-2** — Dado el cliente toca la Mesa 5, cuando la mesa queda seleccionada, entonces la pantalla resalta la Mesa 5 y habilita el botón de continuar.
- [ ] **CA-3** — Dado el cliente no ha seleccionado ninguna mesa, cuando toca 'Continuar', entonces la pantalla no avanza y señala que debe elegir una mesa.
- [ ] **CA-4** — Dado el cliente toca una mesa marcada como no disponible, cuando el toque se registra, entonces la pantalla no selecciona la mesa y explica que está ocupada.

## 4. Contexto

El restaurante identifica al cliente por el número de mesa.

La selección ocurre antes del pago y queda asociada al pedido.

## 5. Reglas de negocio

- Cada pedido queda asociado a una única mesa.
- Solo se pueden seleccionar mesas habilitadas.
