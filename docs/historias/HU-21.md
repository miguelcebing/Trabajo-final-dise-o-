**Como** cliente

**Quiero** registrar mi nombre y un medio de contacto al pagar

**Para** que mi pedido quede identificado y puedan llamarme si hace falta

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente está en el resumen del pedido, cuando toca 'Pagar', entonces la pantalla muestra el formulario con los campos 'Nombre' y 'Teléfono o correo' y el pedido aún no se paga.
- [ ] **CA-2** — Dado el cliente completa nombre y contacto válidos, cuando toca 'Continuar al pago', entonces la pantalla avanza a la confirmación del pago con los datos registrados.
- [ ] **CA-3** — Dado el cliente deja un campo obligatorio vacío, cuando toca 'Continuar al pago', entonces la pantalla señala el campo pendiente y no avanza.
- [ ] **CA-4** — Dado el cliente escribe un contacto con formato inválido, cuando intenta continuar, entonces la pantalla indica el formato esperado y no avanza.
- [ ] **CA-5** — Dado el cliente toca un campo del formulario, cuando el campo recibe el foco, entonces se abre el teclado en pantalla y el campo activo se resalta con un área táctil mínima de 88 px.

## 4. Contexto

Antes de confirmar el pago, el cliente deja su nombre y un medio de contacto.

Estos datos acompañan al comprobante y al pedido, además del número de mesa.

## 5. Reglas de negocio

- El nombre y un medio de contacto, teléfono o correo, son obligatorios.
- Los datos de contacto se asocian al pedido y no se comparten con terceros.
- El pedido no se envía a cocina sin pago confirmado, aunque los datos estén completos.
