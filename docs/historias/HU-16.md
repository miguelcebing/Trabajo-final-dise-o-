**Para** llevar control de lo que salió de mi estación

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cocinero terminó una tarea de su sector, cuando consulta la lista de completados, entonces la tarea aparece con el número de pedido, la mesa y la hora de completado.
- [ ] **CA-2** — Dado el cocinero necesita ver el detalle de un completado, cuando toca la tarea completada, entonces la pantalla muestra los ítems que preparó ese sector.
- [ ] **CA-3** — Dado el turno avanza, cuando el cocinero consulta el contador, entonces la pantalla muestra el total de tareas completadas por el sector.

## 4. Contexto

El sector conserva la lista de tareas completadas del turno para consulta rápida.

Solo incluye las tareas del sector, no las de los demás.

## 5. Reglas de negocio

- Cada sector ve solo sus tareas completadas.
- Las tareas completadas del turno no se eliminan hasta el cierre del turno.
