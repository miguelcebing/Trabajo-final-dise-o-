## 2. Historia

Como **cliente** quiero agregar productos al carrito para armar mi pedido completo antes de pagar.

## 3. Contexto

El cliente elige la cantidad y agrega el producto al carrito.

El carrito conserva lo agregado mientras el cliente sigue consultando el menú.

## 4. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente está en el detalle del producto con sus opciones confirmadas, cuando toca 'Agregar al carrito', entonces el producto aparece en el carrito con la cantidad y el precio del ítem.
- [ ] **CA-2** — Dado el cliente agrega el mismo producto con las mismas opciones dos veces, cuando confirma el segundo agregado, entonces el carrito suma la cantidad en una sola línea del producto.
- [ ] **CA-3** — Dado el cliente aumenta la cantidad a 3 antes de agregar, cuando toca 'Agregar al carrito', entonces el carrito registra 3 unidades y multiplica el precio del ítem por 3.
- [ ] **CA-4** — Dado el cliente no ha agregado ningún producto, cuando consulta el botón del carrito, entonces el botón muestra el contador en cero y no permite continuar al pago.

## 5. Reglas de negocio

- El carrito conserva su contenido mientras la sesión del kiosco esté activa.
- Un ítem con las mismas opciones se acumula en una sola línea; con opciones distintas se registra como línea aparte.
