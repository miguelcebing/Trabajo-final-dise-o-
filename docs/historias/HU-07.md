**Como** cliente

**Quiero** revisar el resumen de mi pedido antes de pagar

**Para** confirmar que todo está correcto antes de pagar

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente seleccionó su mesa, cuando la pantalla muestra el resumen, entonces aparecen los ítems con cantidades, el subtotal, el total y el número de mesa.
- [ ] **CA-2** — Dado el cliente detecta un error en un ítem, cuando toca 'Editar pedido', entonces la pantalla regresa al carrito con el ítem señalado para ajustarlo.
- [ ] **CA-3** — Dado el resumen está correcto, cuando toca 'Pagar', entonces la pantalla avanza a la captura de los datos de contacto.
- [ ] **CA-4** — Dado el resumen es largo y no cabe en pantalla, cuando desplaza la lista, entonces el bloque de total permanece visible mientras se desplaza la lista.

## 4. Contexto

Es el último punto de control antes del pago.

El cliente ve los ítems, la mesa y los totales, y decide pagar o cancelar.

## 5. Reglas de negocio

- En este alcance el total coincide con el subtotal; no se aplican impuestos ni cargos adicionales.
- El resumen siempre muestra el número de mesa seleccionado.
