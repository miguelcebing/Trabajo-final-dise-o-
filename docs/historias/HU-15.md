**Como** cocinero

**Quiero** marcar mi tarea como lista

**Para** que el pedido avance y el cliente lo sepa

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cocinero terminó la preparación de una tarea, cuando toca 'Marcar como lista', entonces la tarea desaparece de pendientes y la pantalla confirma el completado.
- [ ] **CA-2** — Dado la tarea marcada era la última pendiente del pedido, cuando el sistema registra el completado, entonces el pedido pasa al estado Listo y se avisa al cliente.
- [ ] **CA-3** — Dado quedan tareas pendientes en otros sectores, cuando el cocinero marca su tarea, entonces el pedido permanece en 'En preparación'.
- [ ] **CA-4** — Dado el cocinero toca 'Marcar como lista' por error, cuando el sistema muestra la confirmación, entonces la pantalla permite confirmar o volver antes de completar la tarea.

## 4. Contexto

El avance del pedido depende de que cada sector marque sus tareas.

Al completar la última tarea pendiente, el pedido pasa a Listo.

## 5. Reglas de negocio

- Una tarea marcada como lista no puede desmarcarse desde la pantalla del sector.
- El pedido alcanza el estado Listo cuando todos los sectores completaron sus tareas.
