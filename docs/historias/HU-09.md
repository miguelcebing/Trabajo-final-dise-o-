**Como** cliente

**Quiero** recibir un comprobante con el número de mi pedido

**Para** seguirlo y reclamarlo cuando esté listo

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el pago fue aprobado, cuando termina el pago, entonces la pantalla muestra el número de pedido, la mesa y el resumen de ítems.
- [ ] **CA-2** — Dado el cliente tiene el comprobante en pantalla, cuando toca 'Volver al inicio', entonces la pantalla regresa al inicio del menú y el pedido queda registrado.
- [ ] **CA-3** — Dado el sistema genera el número de pedido, cuando se registra el pedido pagado, entonces el número es único y no se repite entre los pedidos del mismo día.

## 4. Contexto

Al finalizar el pago, la pantalla entrega el número de pedido y el resumen.

El número es el identificador único que el sistema genera para el pedido pagado.

## 5. Reglas de negocio

- El número de pedido es único por pedido.
- El comprobante no reemplaza la factura fiscal.
