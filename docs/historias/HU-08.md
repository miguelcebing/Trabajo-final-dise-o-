**Como** cliente

**Quiero** pagar mi pedido desde la pantalla

**Para** completar la compra sin acudir a caja

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente registró sus datos de contacto y está en la pantalla de pago, cuando toca 'Pagar' con el monto mostrado, entonces la pantalla muestra el estado 'Procesando pago' y bloquea acciones repetidas.
- [ ] **CA-2** — Dado el pago se registra correctamente, cuando termina el procesamiento, entonces la pantalla muestra 'Pago aprobado' y el pedido pasa al estado Pagado.
- [ ] **CA-3** — Dado el pago no puede completarse, cuando el sistema devuelve un error, entonces la pantalla muestra el mensaje de fallo, conserva el pedido en el carrito y permite reintentar.
- [ ] **CA-4** — Dado el pedido quedó pagado, cuando el sistema registra el pago, entonces el pedido se envía a los sectores de cocina según los productos incluidos.

## 4. Contexto

El pago de este alcance es simulado: la pantalla registra la confirmación del cliente y el sistema marca el pedido como pagado.

No hay integración con una pasarela real, pero el flujo deja preparado el punto de integración.

## 5. Reglas de negocio

- Un pedido no se envía a cocina si no está pagado.
- El botón de pago se deshabilita mientras el pago está en proceso.
- El monto pagado es el total mostrado en el resumen.
