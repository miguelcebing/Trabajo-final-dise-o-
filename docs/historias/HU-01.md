**Como** cliente

**Quiero** consultar el menú agrupado por categorías

**Para** encontrar rápido los productos que deseo pedir

## 1. Criterios de aceptación

- [ ] **CA-1** — Dado el cliente está frente a la pantalla táctil en la vista inicial del menú, cuando toca una categoría, por ejemplo Postres, entonces la pantalla muestra solo los productos de esa categoría, con nombre, precio e imagen.
- [ ] **CA-2** — Dado el cliente está en una categoría con más productos de los que caben en pantalla, cuando desplaza la lista con el dedo, entonces la pantalla muestra los productos siguientes sin perder la categoría seleccionada.
- [ ] **CA-3** — Dado la categoría seleccionada no tiene productos disponibles, cuando abre la categoría, entonces la pantalla muestra el mensaje 'Sin productos disponibles' y mantiene visible el botón de carrito.
- [ ] **CA-4** — Dado el cliente toca la tarjeta de un producto, cuando el toque se registra sobre la tarjeta, entonces el área táctil de la tarjeta mide al menos 88 x 88 px y abre el detalle del producto.

## 4. Contexto

Es el primer contacto del cliente con el kiosco. La pantalla muestra el menú completo agrupado por categorías y permite cambiar de categoría con un solo toque.

No requiere autenticación: la identificación del cliente ocurre más adelante, con la mesa y los datos de contacto.

## 5. Reglas de negocio

- El menú se muestra siempre agrupado por categorías; 'Todos' es la vista inicial.
- Los productos marcados como agotados no se muestran en ninguna categoría.
- El precio se muestra con el formato de moneda local.
